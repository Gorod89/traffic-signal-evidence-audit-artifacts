# Data and network licensing notes

No road-network, route, raw-trace, or model-weight files are distributed in this GitHub repository.

The source-tree audit found mixed upstream terms:

- the Moscow network appears to derive from OpenStreetMap material, for which ODbL attribution/share-alike obligations may apply;
- the Cologne scenario carries a CC BY-NC-SA 3.0 indication in the audited materials;
- the Ingolstadt/RESCO materials carry GPL-3.0 indications.

These findings must be checked against the exact source file and upstream version before redistribution. A single MIT license cannot cover all of the data. The archival deposit should provide file-level provenance, upstream URLs/versions, attribution text, and the applicable license for every network and route file. If redistribution is not permitted, the deposit should provide acquisition instructions and checksums instead of copying the asset.
